## Objective

Build a small but impressive prototype that demonstrates:

- Strong automation skills (preferably using n8n or a similar workflow platform)
- Strong software development skills
- Strong product thinking and visual/UI design sense

This task is intentionally open-ended. They are interested in what you choose to
build, how you approach the problem, and the level of quality you deliver in a short
timeframe. **Expected effort: ~1–2 hours.**

## Suggested Direction

Build a visually appealing dashboard or internal tool connected to an automation
workflow. The dashboard should display live or near-live data that can be reviewed
and understood by the evaluator.

### Example Ideas

- Lead intake dashboard ← *(chosen: FlowDeck)*
- Website form activity dashboard
- Automation execution monitor
- Support ticket or WhatsApp message dashboard
- SEO/content pipeline dashboard
- Website uptime or error monitoring dashboard
- AI generation workflow dashboard

You may propose a different concept if it better showcases your skills.

## Requirements

- A visually polished dashboard or internal tool UI
- A real automation/workflow component (preferably n8n)
- A live or simulated-live connection between the workflow and the dashboard
- Meaningful statistics, charts, counters, status indicators, logs, or activity feeds
- Clear evidence that the dashboard is connected to the workflow and not a static mockup
- Workflow export file or a clear explanation of the automation setup
- A publicly accessible deployed URL (Vercel preferred)

## Optional

- GitHub repository access, if you want to share your code
- **Use mock or test data only. Real client data must not be used.**

## Recommended Tools

Claude Code, Codex, n8n, Make / Zapier, Cursor, Lovable, React / Next.js,
Node.js / Python, or any other tools you consider appropriate. They are particularly
interested in how you combine AI-assisted development, automation platforms, and
product/design judgment.
